ウェブブラウザで動作する、ニッチな用途のツールたち。

利用可能なツール

ハッシュ値に基づく 127.x.x.x 生成

入力されたドメイン名ラベル（小文字、63バイト制限）のSHA-256ハッシュ値を計算し、巨大な整数を254進数（1-254表記）およびローカルIPアドレス風形式（127.B1.B2.B3）で表示します。

文字列からプライベートポート番号を生成

文字列（サービス名など）から、IANAプライベートポート範囲 (49152-65535) の一意なポート番号を生成します。開発環境のポート重複回避に便利です。

Drop Event Tester

ブラウザが受け取るドラッグ＆ドロップイベントのメタデータを解析し、DataTransferに含まれるアイテムの種類、ファイル名、テキスト内容などを表示します。

Clipboard API 総合実験

ブラウザの Clipboard API の挙動を確認するための実験ページです。画像（Data URL / ファイル）や HTML 形式でのコピーを試せます。

Android App Launch Tester

Android の intent: スキームやカスタムスキームを使用して、ウェブページからアプリを起動する挙動の実験用ページです。

UUID v3/v5 Generator

RFC 9562 準拠の名前ベース UUID (v3/v5) 生成と検証ツール。ライブラリ実装とネイティブアルゴリズムの整合性を確認できます。

UUID v4 Generator

RFC 9562 準拠の完全ランダムな UUID (v4) 生成ツール。一括生成、クリップボードコピー、詳細なビット解析機能を備えています。

MicroPython REPL

WebAssembly Port の MicroPython をブラウザ上で実行。軽量な Python 環境での学習や実験が可能です。

Pyodide REPL

フル機能の Python 3.13 環境をブラウザ上で実行。科学計算ライブラリなどもサポートする強力な実行環境です。

Web NFC Tester

Android版Chromeなどで利用可能なWeb NFC APIの実験ツール。NFCタグのシリアル番号取得やNDEFレコード（Text, URL等）の読み取り内容をリアルタイムで表示します。

hello generative language api

Google Gemini / Gemma API を直接操作できるマルチエージェント・プレイグラウンド。最新の v3/v2.5 モデルや画像解析、思考プロセスの可視化に対応しています。
