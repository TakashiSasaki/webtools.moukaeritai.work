# 文字列ハッシュ値の254進数表示 (127.html)

`127.html` は、入力された任意の文字列（ドメイン名ラベルなど）から SHA-256 ハッシュ値を計算し、それを元にユニークなローカル IP アドレス (`127.x.x.x`) や、その他の数値表現を表示するツールです。

## 概要

このツールは、主にローカル開発環境などで、特定のプロジェクトや識別子に紐付いたユニークなループバックアドレスを決定するために使用されます。文字列から一意な IP アドレスを生成することで、設定ファイルの管理を容易にしたり、ポート番号の衝突を回避する際の参考にしたりできます。

## 入力仕様

*   **入力欄**: テキストボックスに文字列を入力します。
*   **使用可能な文字**: 小文字の英数字 (`a-z`, `0-9`) とハイフン (`-`) のみ。
    *   大文字が入力された場合は、自動的に小文字に変換されます。
    *   上記以外の文字（記号やスペースなど）は自動的に削除されます。
*   **長さ制限**: 最大 **63バイト**。
    *   入力がこの長さを超えた場合、63バイトに収まるように切り詰められます（ドメイン名ラベルの仕様に準拠）。

## 処理ロジック

入力された文字列に対して、以下の手順で計算が行われます。

1.  **SHA-256 ハッシュ計算**:
    *   入力文字列を UTF-8 エンコーディングでバイト列に変換します。
    *   Web Crypto API を使用して、そのバイト列の SHA-256 ハッシュ（32バイト）を計算します。

2.  **IP アドレス生成 (127.B1.B2.B3)**:
    *   計算されたハッシュ値の**最初の3バイト**を使用します。
    *   それぞれを10進数に変換し、`127.{byte1}.{byte2}.{byte3}` の形式で表示します。
    *   これにより、約 1677万通りのユニークなループバックアドレスが生成されます。

3.  **各種数値表現の生成**:
    *   **16進数 (Hex)**: ハッシュ値全体（32バイト）を16進数文字列（64文字）で表示します。
    *   **10進数 (Decimal)**: ハッシュ値全体を1つの巨大な整数（BigInt）として10進数で表示します。
    *   **254進数 (Base254, 1-based)**:
        *   ハッシュ値の巨大な整数を、基数 254 の特殊な記数法で表現します。
        *   **Bijective numeration (全単射記数法)** を採用しており、各桁は **1 から 254** の値を持ちます（0 は使用されません）。
        *   これは、IPアドレスのオクテットとして 0 や 255 を避けたい場合などに有用な表現です。

## 機能

*   **自動再計算**: 入力欄の内容を変更すると、即座に結果が再計算されます。
*   **クリップボードコピー**: 生成された IP アドレスをワンクリックでコピーできます。
*   **リンク機能**: 生成された IP アドレス (`http://127.x.x.x` または `https://127.x.x.x`) を新しいタブで開くボタンがあります。これにより、ローカルサーバーがそのアドレスで待機しているか即座に確認できます。

## 用途

*   **ローカル開発**: プロジェクト名 (例: `my-project`) から `127.x.x.x` のアドレスを生成し、`/etc/hosts` に登録して使用する。
*   **識別子の数値化**: 文字列を一意な数値リストに変換したい場合の参考として。
