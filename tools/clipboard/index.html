Clipboard API 総合実験ページ（dataURL + file src）

使い方 (README)

このページは Clipboard API の挙動を環境差（OS/Browser/App）込みで繰り返し観測するためのベンチです。
ファイル画像の実験には、同一ディレクトリに以下の各形式（image1_small.* など）を配置してください：
png, jpg, webp, gif, bmp, ico, avif
※推奨：http://localhost などで配信して開く（file:// は制限が出やすい）

A. data URL 生成画像（Canvas / IMG 同時表示）

image/png (Binary): Canvasから生成したバイナリデータを直接コピーします。ペイントソフトやSlackへの「画像」としての貼り付けに最適です。
text/html (DataURL): 画像をBase64文字列化した状態でタグとしてコピーします。Officeアプリ等に「レイアウトを維持したまま画像付き」で貼り付けられます。

B. ファイル画像（IMG の src が imageN_small.ext）

※ Word などへの貼り付けは、通常 text/html が最も再現性高く複数画像を展開しやすいです。
表示中のファイル IMG（div で囲われた実体）
相対パス HTML: src="image1_small.png" のままコピーします。貼り付け先が同じディレクトリ構成でないとリンク切れになります。
DataURL化 HTML: コピー直前に画像をBase64に変換してタグに埋め込みます。どこに貼り付けても画像が表示される最も堅牢なHTMLコピーです。
Raw Blob / 再変換PNG: 純粋なバイナリデータとしてコピーします。「Raw」はサーバーから取得した形式のまま、「再変換」はブラウザのCanvasで描き直したPNGを渡します。
