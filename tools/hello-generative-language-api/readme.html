AI Playground v6 について

AI Playground v6 は、Google が提供する Generative Language API (Gemini / Gemma) を直接ブラウザから呼び出し、最新の AI モデルと直感的に対話するためのプレイグラウンドです。 開発者、リサーチャー、そして AI の可能性を探索したいすべての人のために設計されています。

主な特徴

  • 最新モデルへのアクセス: Gemini 2.5 Flash や推論特化型の Flash Thinking、最新のオープンウェイトモデル Gemma 3 など、Google の最新 AI を選択可能です。
  • 思考プロセスの活用: 推論モデル (Thinking) を使用することで、AI がどのようプロセスを経て回答を導き出したかを確認する体験が可能です。
  • セキュアな設計: API キーはブラウザの localStorage にのみ保存され、外部サーバーへ送られることなく、直接 Google API と通信します。
  • 堅牢な通信: 指数関数バックオフアルゴリズムによる自動リトライ機能を備えており、通信不安定時やレートリミット発生時でも安定して動作します。

対応モデル

本ツールでは以下のカテゴリのモデルを選択できます。

  • Specialized Models: 推論能力を高めた Gemini 2.0 Flash Thinking や Robotics 向け調整モデルなど。
  • Gemini Series: 高速かつ高性能な Gemini 2.5 Flash、軽量な Flash-Lite など。
  • Gemma 3: 1B から 27B まで、デバイス上での動作やサーバーサイドでの高度な推論に適した多様なサイズを選択可能です。

使い方

  1. Google AI Studio で API キーを取得します。
  2. 画面右上の設定ボタン（ギアアイコン）をクリックします。
  3. 取得した API キーを入力し、Save Key をクリックして保存します。
  4. 画面上部のドロップダウンから対話したいモデルを選択します。
  5. 入力欄から指示や質問を送信し、対話を開始します。
ヒント: 「思考プロセス」を重視したい場合は、モデル選択で Thinking と記載されたモデルを選択することをお勧めします。

技術仕様

  • インターフェース: Tailwind CSS を使用したモダンでレスポンシブなデザイン。
  • 状態管理: 選択されたモデルや API キーはブラウザを閉じても保持されます。
  • エラーハンドリング: API のエラーメッセージを詳細に表示し、トラブルシューティングを容易にします。
