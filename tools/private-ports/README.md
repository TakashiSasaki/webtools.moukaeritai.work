IANAではプライベートポート番号として
49152 ～ 65535 が割り当てられている
65535 - 49152 + 1 = 16384 個のポートがこの範囲に割り当てられている。

private-ports/index.html では
人間にとって覚えやすい文字列からこの16384個のポートへの単射を計算する。

  **SHA-256 ハッシュ計算**:
    *   入力文字列を UTF-8 エンコーディングでバイト列に変換します。
    *   Web Crypto API を使用して、そのバイト列の SHA-256 ハッシュ（32バイト）を計算します。

 ハッシュ値は大きな桁数の整数なわけであるが、
 これを16384で割った余りに 49152 を加算して
 その文字列に対応するポート番号とする。
