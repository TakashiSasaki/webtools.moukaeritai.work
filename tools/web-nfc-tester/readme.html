Web NFC Tester について

Web NFC Tester は、ブラウザ標準の Web NFC API を使用して、物理的な NFC タグ（ICタグ）の内容を読み取り、その情報を技術的に解析するためのツールです。 開発者が、自身の端末で Web NFC がどのように動作するかを確認するためのテスト環境として設計されています。

注意: このツールは執筆時点（2026年）でも、主に Android 版の Google Chrome などの一部のブラウザでのみ動作します。 iOS (iPhone/iPad) やデスクトップブラウザではサポートされていません。

主な機能

  • NFC読み取り (Scan): 近傍にある NFC タグを検出し、情報の取得を開始します。
  • シリアル番号の取得: タグ固有の識別子 (UID) を表示します。
  • NDEF レコード解析: タグに書き込まれている Text 形式や URL 形式のデータを抽出・表示します。
  • ログ機能: 読み取った履歴をリスト形式で保持し、複数のタグを連続してテストできます。

動作要件

  • 対応端末/ブラウザ: Android (Chrome 89+ / Edge / Samsung Browser 等)
  • ハードウェア: NFC 機能を搭載したデバイスであること
  • 設定: 端末の NFC 設定が「オン」になっていること
  • セキュリティ: HTTPS 環境でのアクセス、およびユーザーの明示的な操作（ボタンクリック）による許可が必要です。

技術的な詳細

このツールは NDEFReader インターフェースを使用しています。 NFC タグには NDEF (NFC Data Exchange Format) という標準化されたデータ形式で情報が格納されており、本ツールは以下のレコードタイプを優先的にデコードします。

  • text: プレーンテキストデータ
  • url: WebサイトのURLなどのリンク
  • その他: バイナリデータとしてサイズを表示

API で取得可能な情報

Web NFC API の onreading イベントで取得できる情報は以下に限定されます。

  • serialNumber: タグの固有識別子 (UID)。コロン区切りの16進数文字列
  • message.records: NDEF レコードの配列（recordType, data, encoding, lang, mediaType, id）

API の制限事項

⚠️ 重要: Web NFC API はセキュリティとプライバシーのために高レベル抽象化されており、以下の情報は取得できません。
  • NFC技術タイプ: NFC-A (MIFARE)、NFC-F (FeliCa)、NFC-B、NFC-V の区別は不可
  • タグの種類: MIFARE Classic、MIFARE Ultralight、FeliCa Lite 等の識別は不可
  • ATQA/SAK: NFC-A のアンチコリジョン応答は取得不可
  • IDm/PMm: FeliCa 固有の識別情報は取得不可
  • メモリ容量: タグの総容量は取得不可
  • 低レベルコマンド: APDU コマンドの送信は不可（NDEF形式のみサポート）

NFC 技術タイプの識別やカード固有の詳細情報が必要な場合は、Android や iOS のネイティブアプリ開発が必要です。
